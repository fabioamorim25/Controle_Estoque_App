# Controle_Estoque_App
Sistema de Controle de Estoque focado em solucionar a gestão de produtos e fornecedores de uma empresa



### Etapas:
    - modelagem dos requisitos
    - Criar Backend
    - Criar Frontend


### Funcionalidades:
    O sistema contempla 3 funcionalidades principais (features):

    - Cadastro de Fornecedor: Permite registrar, validar e gerenciar fornecedores (Nome, CNPJ, Endereço, Telefone, E-mail e Contato).
    
    - Cadastro de Produtos: Permite incluir produtos com código de barras, descrição, preço, quantidade, categoria, validade e imagem.
    
    - Associação Produto/Fornecedor: Gerencia a relação "muitos para muitos" (N:N), permitindo vincular e desvincular fornecedores a produtos específicos.
